Deliberately left out

A filter considered and rejected, with the reason, stops the same debate recurring in two weeks.

  • In stock — Moved to a toggle above the results. Single binary, and the rail slot is worth more to a class filter.
  • Colour — Fixed per material — CPVC is cream, uPVC white or grey, SWR usually white. One value per branch, so it eliminates nothing.
  • Application — Restates pressure class exactly. 'Hot water' is what SDR-11 means; showing both splits the result set twice for one decision.
  • PPR (PN 10–25) — A real system, but commercial and industrial rather than residential, and the collection sweep found no PPR supply in either target city. Left out rather than shipped as an empty branch — if PPR appears in a later run it earns a sixth System value and its own conditional PN filter.
  • Seller rating — Held back until there is a real ratings corpus.
